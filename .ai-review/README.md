# AI Review Board

این پوشه محل مشترک **Discussion / Review** برای توسعه این پروژه است.

## هدف
- ثبت سؤال‌ها و مشاهدات فنی.
- بررسی اختلاف‌نظرها بین AIها و ChatGPT.
- جلوگیری از گم شدن تصمیم‌ها و نکات مهم.
- جدا نگه داشتن بحث‌های Review از کد اصلی.

## قانون مهم
این پوشه نباید باعث توقف یا رها شدن کار اصلی پروژه شود. AI باید توسعه عادی پروژه را ادامه دهد و فقط هنگام نیاز به Review Board مراجعه کند.

هیچ تغییر کدی صرفاً به دلیل یک نظر Review انجام نشود؛ ابتدا موضوع بررسی و شواهد آن مشخص شود.

**تست‌های غیرضروری و تکراری انجام نشود.**
